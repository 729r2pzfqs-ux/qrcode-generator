Qu'est-ce qu'un QR Code WiFi?

Un QR code WiFi encode vos identifiants réseau (SSID, mot de passe et type de sécurité). Au scan, la connexion au réseau WiFi est proposée — pas besoin de taper.

Créer un QR Code WiFi

  1. Trouver vos infos WiFi: Nom du réseau (SSID) et mot de passe.
  2. Choisir le type de sécurité: La plupart des réseaux utilisent WPA/WPA2.
  3. Générer le code: Entrer les infos dans notre générateur WiFi QR.
  4. Imprimer ou afficher: Placer à un endroit visible pour les invités.
