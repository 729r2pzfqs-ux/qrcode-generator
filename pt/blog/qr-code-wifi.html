O que é um QR Code WiFi?

Um QR code WiFi codifica suas credenciais de rede (SSID, senha e tipo de segurança). Ao escanear, a conexão à rede WiFi é oferecida — sem digitar.

Criar um QR Code WiFi

  1. Encontre seus dados WiFi: Nome da rede (SSID) e senha.
  2. Escolha o tipo de segurança: A maioria das redes usa WPA/WPA2.
  3. Gere o código: Digite os dados no nosso gerador WiFi QR.
  4. Imprima ou exiba: Coloque em local visível para convidados.
